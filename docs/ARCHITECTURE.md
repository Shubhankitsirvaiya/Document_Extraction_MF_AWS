# Architecture and execution contract

## Why the service is asynchronous

PDF rendering and vision-model calls can take longer than a normal HTTP request. The API
therefore accepts work and returns a job ID. SQS absorbs bursts, the dispatch Lambda
leases one attempt, and AgentCore immediately returns `ACCEPTED` while a background
thread performs the long operation. `add_async_task` and `complete_async_task` keep the
AgentCore session health state accurate while `/ping` remains responsive.

```text
Local Streamlit --AWS profile/SigV4--> HTTP API --> API Lambda --> S3 + DynamoDB
                                                          |
                                                          v
                                                         SQS --> Dispatch Lambda
                                                                    |
                                                                    v
                                                         AgentCore async runtime
                                                         | input validator Lambda
                                                         | LangGraph/PyMuPDF/Bedrock
                                                         | output validator Lambda
                                                         v
                                                     S3 result + DynamoDB status

EventBridge Scheduler --> Reconcile Lambda --> recover leases / completion event
Completion EventBridge bus ------------------> CloudWatch event log
```

## LangGraph stages

The graph is one deterministic extraction pipeline, not a multi-agent system:

1. `validate_input`: the AWS path must invoke the dedicated input-validator Lambda.
2. `parse`: PyMuPDF extracts text and renders upright page PNGs.
3. `select_pages`: regex hits, low-text/scanned pages, and neighboring pages are selected.
4. `extract_batches`: a configured Bedrock model receives at most two pages per call.
5. `merge`: exact duplicate restrictions are removed conservatively.
6. `persist_candidate`: the strict versioned result schema is serialized.
7. `validate_output`: the dedicated output-validator Lambda verifies IDs, hashes,
   quotes, pages, coordinates, mock markers, and duplicate IDs.
8. `finalize`: only a validated candidate becomes the result artifact.

## Job state machine

```text
UPLOADING -> QUEUED -> DISPATCHING -> VALIDATING_INPUT -> PARSING
    -> SELECTING_PAGES -> EXTRACTING -> VALIDATING_OUTPUT
    -> COMPLETED | COMPLETED_WITH_WARNINGS | REJECTED | FAILED
```

Terminal states are immutable. The dispatch lease allows SQS retries without creating
concurrent attempts. Each accepted attempt receives a UUID `attempt_id`; every runtime
write includes a DynamoDB conditional expression for that ID. Reconciliation can fail a
stale attempt, after which that old worker can no longer alter the job.

## Data ownership

- The local UI signs API requests with temporary credentials from the named AWS profile;
  no access key is stored in the application or browser.
- API Gateway derives `owner_id` from IAM request context, never from request JSON.
- S3 input keys are generated by the API (`jobs/<job>/input/document.pdf`).
- `GET /jobs/{id}` checks ownership and returns a five-minute result URL only at terminal
  state.
- The runtime receives only `job_id`, `attempt_id`, and correlation metadata; it reloads
  the authoritative record from DynamoDB.

## Evidence and localization

The model returns a verbatim quote, page number, normalized `[0,1]` bounding boxes, and
render dimensions. Normalized coordinates keep evidence stable when the UI resizes the
page image. Model boxes start as `UNVERIFIED`; a full-page box is warned about, missing
localization is visible, and unsupported quotes fail validation on text-bearing pages.

Local mock boxes are marked `bbox_source=MOCK`. The AWS validator rejects them.

## Recovery behavior

- SQS retries dispatch errors and moves repeated failures to a DLQ.
- The dispatch Lambda uses a short conditional lease before invoking AgentCore.
- The runtime emits application heartbeats independently of extraction work.
- EventBridge Scheduler invokes reconciliation every minute.
- Reconciliation resends interrupted enqueues, expires dispatch leases, fails stale
  processing attempts, and publishes pending terminal events.
- CloudWatch alarms expose queue age and DLQ depth; the dashboard also shows Lambda
  errors and DynamoDB throttling.

AgentCore auto-instrumentation is intentionally disabled until
`aws-opentelemetry-distro` is explicitly bundled in its direct-code artifact. Managed
runtime logs remain enabled, while the five Lambda functions continue to emit X-Ray
traces.
